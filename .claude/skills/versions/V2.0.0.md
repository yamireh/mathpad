# MathPad — V2.0.0 Scope (Parent Pro)

**Marketing version 2.0.0 = Parent Pro.** Expands Parent Mode from a passive
dashboard into an active tool: **targets & stars** and **parent-assigned exams**,
sold as a **subscription**. Full design in `docs/parent-pro.md`.

> **Naming note:** the older `V2.0.md` in this folder is the **Clock** module,
> which actually shipped as **marketing version 1.2.0** — the roadmap numbering
> drifted from real app versions. This doc (`V2.0.0.md`) is the true **2.0.0**
> app release.

> **Status (2026-07-25):** In development on branch `parent-pro`. `main` stays on
> the shipping 1.2.x line for hotfixes. Decisions captured; no feature code yet.

## What's IN 2.0.0

- **Targets & Stars** (build first): parent sets daily/weekly/monthly goals
  (total + per-topic); kid earns a **star** on meeting a goal. Two counters —
  `starsLifetime` (never decremented) + `starsBalance` (redeemable). Parent
  "resets" (redeems) the balance; a redemption is logged as history. Rides on the
  existing session aggregates; **parent app is authoritative** for awarding.
- **Assigned exams** (build second): parent authors a custom exam (pick mode +
  settings + count → generated, plus optional hand-entered problems), assigns to
  a child. Kid sees **pending exams**, runs one in the existing practice
  workspace, submits. **Blind results** — kid sees "Submitted ✓", parent sees the
  score.
- **Monetization:** **Parent Pro subscription** gating both, under a `parentPro`
  entitlement. Basic dashboard stays **free**. See the `pricing` skill §0.

## What's NOT in 2.0.0 (deferred)

- New kid **learning modules** (Shapes / Axis / Money) — their own later versions.
- Any kid-facing subscription/upsell — Pro is parent-authenticated only.
- Star mechanics inside the kid practice (stays calm/un-gamified per SPEC).

## Mandatory before prod

- Subscription product(s) set up in App Store Connect / Play Console; StoreKit +
  Play Billing entitlement wired (Parent Mode already talks to both).
- Firestore **rules** for the new collections (targets, redemptions, exams,
  examResults) — re-deploy required.
- Price + period finalized; Apple Family Sharing enabled on the sub.

## Open (decide before/while building)

- Price + period; free/paid boundary specifics; star-award authority (confirm
  parent-authoritative); subscription entitlement storage/validation; redemption
  UX. (See `docs/parent-pro.md` → Open decisions.)

## Rules

1. **Reuse, don't fork** — exams run in the existing workspace; stars ride on the
   existing aggregates + sync.
2. **Parent-authenticated only** — no Pro surface is kid-facing.
3. **Everything behind `parentPro`** so we can ship dark and flip payment on.
