## Fixes & changes

### Clock — "write the time" recognition
- **Fixed a written "1" being scored as "7".** The answer is now judged from
  the field's own recognized digits instead of re-recognizing a regenerated
  glyph (the displayed value and the scored value could disagree).
- **Ported the 1↔7 / 0↔6 disambiguation into `recognizeNumber`** (per digit),
  so multi-digit numbers containing a 1 are corrected too.
- **Recover numbers ML Kit can't read whole** (e.g. "11" as bare vertical
  strokes) by segmenting the ink and recognizing each digit on its own.
- New `answerDigits` helper + regression tests.

### Startup — instant navigation
- **First open of a topic is no longer janky.** A launch overlay (`AppPrewarm`,
  matching the native splash) warms the heavy Clock / Operations module graphs,
  the Skia renderer, and the recognition model, and waits for entitlements to
  settle before revealing the app. Hard-capped so it can never trap the user;
  no new native dependency.
