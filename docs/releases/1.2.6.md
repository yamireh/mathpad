# v1.2.6

_Date: 2026-07-24_

Kids'-QA batch: fixes surfaced by real on-device testing across Division,
Clock, Multiplication, and the practice screen.

## Fixes & changes

### Division
- **No more repeated problems from an impossible setup.** Divisor-digits can no
  longer exceed dividend-digits (the settings auto-adjust), and the generator
  clamps + varies its fallback — so a session can never fill with one repeated
  problem (the "12 ÷ 4 four times in a row" bug).
- **Draft cells show a clean printed blue digit** (the kid's own recognized
  digit) instead of the semi-printed stroke glyph.

### Clock
- **Results page:** Home / Try again are pinned; the correct answer shows in
  words for the words/tiles mode (e.g. "quarter past 1").
- **Tiles mode:** a × delete icon on placed tiles; the bank is grouped into
  **Minutes / Past-or-to / Hour**, with _o'clock_ living in the Hour section;
  fixed the tile area shrinking.
- **"Move on without answering?"** confirmation before advancing a blank
  question (matches operations).
- **Practice header:** solid background + a full-width progress bar that doubles
  as the header divider (replaces the hard line).

### Multiplication
- **Missing carry box fixed.** The leftmost sum-carry box is now kept when a
  partial product reaches that column and it receives a carry (e.g. 68 × 12).
- **Tall problems stay usable on small phones:** the writing pad has a minimum
  height, the problem scrolls vertically, and the view auto-scrolls down to the
  answer boxes.

### Feedback
- **Fixed the intermittent missing correct/wrong sound** — the clip now plays
  only after its async seek-to-start resolves.

### Force update
- **"Update" now opens THIS app on the correct store:** Play Store via the
  package id, App Store via id `6785151405`, with a store-app deep link and an
  https fallback.
