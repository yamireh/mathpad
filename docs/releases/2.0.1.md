# v2.0.1

_Date: 2026-07-30_

Fixes and polish on top of the Parent Pro 2.0.0 release — most importantly,
kid devices can now join a family again.

## Fixes & changes

### Family linking
- **Fixed: kids couldn't join a family** — the code-join hit a Firestore
  permission error (the client tried to count children, which a not-yet-member
  kid device isn't allowed to do). Joining works again; the 5-child cap stays
  enforced parent-side.
- **Disconnect now cleans up** — leaving a family removes this device's child
  record (and its sessions), so the parent dashboard shows only the kids who are
  currently linked. Reconnecting never leaves a duplicate/ghost.

### Parent Pro
- **Hidden from linked kids** — a device already linked as a child no longer
  sees the Parent Pro subscription entry (and the paywall route bounces it back).
  The subscription is for a parent setting up their own family.

### Division
- **Clearing an answer box clears the stale work below it** — in division, a
  quotient digit drives its product row, difference, and every later digit, so
  clearing an upstream box mid-solve now also clears what depended on it.

### Support & links
- Updated the **privacy** and **support** links, and added an **FAQs** button on
  the Support screen.
