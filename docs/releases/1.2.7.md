# v1.2.7

_Date: 2026-07-25_

Division scratch pad — a place to work out the quotient digit.

## Fixes & changes

### Division
- **New scratch pad for working out.** Long division (and inline division) now
  has a floating **"✎ Scratch"** button. Tapping it slides a full scratch canvas
  up over the problem so the kid can estimate the next quotient digit — e.g.
  "how many 82s in 735?" → try 82×8 = 656, 82×9 = 738 ✗ → 8 — then close it to
  return to the question with everything untouched.
  - The structured staircase holds the _result_ of each step; this gives kids
    the free space to _find_ it, which 2-digit divisors (÷82) really need.
  - Scribbles persist per question (reuses the same `scratchInk` as the
    +/−/× layout), so reopening shows prior work.
