# v2.0.2

_Date: 2026-07-31_

Parent Pro goes live for real, on a redesigned, tamper-proof family-linking model
— plus offline hardening and a settings clean-up.

## Fixes & changes

### Parent Pro is live
- **Enabled Parent Pro in production.** The whole parent experience
  (progress / goals / practice, the paywall, rewards, exams) was hidden in
  release builds behind a dev flag; it's now on.

### Family linking — fixed 5-slot model
- **Rebuilt how kids join a family.** Each family now has a fixed pool of **5
  join codes**. The parent taps **Add child**, names them, and shares that
  child's code; the child enters it and taps **Start practice**.
- **The 5-child cap is now structural** (only 5 codes exist) and, together with
  single-use join, is enforced in the security rules — a code can't be reused on
  a second device.
- **Stable identity:** a child is a slot, so reinstalling the app and re-joining
  with the same code keeps the same child — no more duplicate/ghost entries.
- **Disconnect is parent-controlled:** **Re-issue** (move a child to a new
  device) and **Remove** (free the slot). Kids rename themselves locally only.

### Offline
- **Family-subscription unlock now works offline.** A kid unlocked by the family
  subscription stays unlocked when offline (last-known status is cached), instead
  of locking on a cold start. Practice progress still queues locally and syncs
  when the connection returns.
- Clearer "no internet" messages in parent mode.

### Settings & polish
- Grown-ups menu tidied: **Connect to family** (kid devices), **Go to dashboard**
  for a signed-in parent, and no confusing duplicate rows.
- Fixes: a stale family pointer no longer errors the parent screen; the join-code
  and child-name placeholders render cleanly; the dev toggle moved out of the way.
