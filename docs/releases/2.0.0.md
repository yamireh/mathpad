# v2.0.0 — Parent Pro (IN DEVELOPMENT)

_Status: in development on branch `parent-pro`. Living draft — fixes/features
recorded here as they land; finalize before shipping._

Major release: **Parent Pro** — targets & stars and parent-assigned exams, sold
as a subscription. Design: `docs/parent-pro.md`. Scope: `versions` skill →
`V2.0.0.md`.

## Planned

### Parent Pro — Targets & Stars
- Parent sets daily/weekly/monthly goals; kid earns stars for meeting them.
- Lifetime + redeemable star counters; parent redeems; redemptions kept as
  history.

### Parent Pro — Assigned exams
- Parent authors + assigns custom exams; kid completes them; blind results (kid
  submits, parent sees the score).

### Monetization
- Parent Pro **subscription** (`parentPro` entitlement). Basic dashboard stays
  free. Kid learning modules remain one-time IAPs.

## Landed so far

- Decisions captured: `docs/parent-pro.md`, `pricing` skill §0, SPEC stars
  carve-out, `versions` skill V2.0.0. Branch `parent-pro` created off `main`;
  version bumped to 2.0.0.
- Targets & Stars **Slice 1** — pure `lib/rewards/` logic (window math,
  per-window progress, idempotent star evaluation), framework-free + fully
  unit-tested (`__tests__/rewards.test.ts`). No Firebase/UI yet.
- Targets & Stars **Slice 2** — Firestore layer (`lib/firebase/rewards.ts`):
  targets CRUD, star summary, redemptions, and `evaluateAndAward` (runs the pure
  logic against Firestore, idempotent). Stars live in child **subcollections**
  so `resetChild` can't wipe them; `removeChild` + family deletion purge them.
  Firestore rules added for the new subcollections (kid read-only; parents
  write). **Rules re-deploy required before prod.** No UI yet.
- Targets & Stars **Slice 3** — Parent UI in the dashboard's expanded child card
  (`RewardsSection`): stars earned + to-spend, each goal with a live
  current-window progress bar, **Set/Edit goal** (`SetGoalDialog` — period +
  total + optional per-topic) and **Redeem** (spend stars + note). Runs
  `evaluateAndAward` on open via a new `useChildRewards` hook. Gated by a
  `PARENT_PRO_ENABLED` flag (`__DEV__` — hidden in prod builds).
